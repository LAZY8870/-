# 以 Python QR Code 導引手機連線至本機網站

> 報告模板。請在本人實際執行後填寫方括號內容，並附上原始紀錄或截圖；不要虛構掃描、連線或裝置結果。公開報告前請遮蔽來源 IP、訪客資訊與其他個資。

## 目的

本作業以 Python 將網址轉換成 QR Code，讓使用者以手機掃描即可開啟網頁，避免手動輸入網址。本程式也會自行解碼所產生的 QR 圖片，核對內容是否與原網址一致；再由電腦啟動個人頁面和區域網路伺服器，讓同 Wi-Fi 的手機掃描連線，並記錄連線時間、來源 IP 與瀏覽器。預期藉由產生、解碼、手機掃描和伺服器紀錄驗證 QR Code 導引流程。

## 3.2 QR Code 原理簡述

QR Code 版本由 1 至 40；版本 n 的正方形矩陣邊長為 4n + 17 個模組。模組是構成黑白圖樣的基本單元。容錯等級 L、M、Q、H 約可修復 7%、15%、25%、30% 的損毀資料；較高容錯可能讓同樣內容的圖樣更密。

- 本次實際產生：版本 [值]、[模組數] × [模組數]、容錯 [L/M/Q/H]。
- 比較四種容錯的圖片像素／檔案大小／掃描結果：[填寫 `compare` 實測數據]

## 3.3 程式架構說明

- `make`：使用 `qrcode` 及 Pillow 產生 PNG，可加標籤；列出版本、模組數、像素和檔案大小。
- `decode`：使用 OpenCV `QRCodeDetector` 解碼指定圖片。
- `compare`：以 L、M、Q、H 四種容錯各產生一張圖片，再用 OpenCV 比對原始網址。
- `serve`：使用 Python `http.server` 架設個人頁，產生區網 QR Code，並記錄每次頁面存取時間、來源 IP、瀏覽器及簽到事件。
- 結果紀錄：每次命令在 `results/` 留下 Markdown 與 JSON。
