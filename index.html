安全地讀取與寄送 Gmail

使用 Google 官方授權視窗登入，不需要輸入 Gmail 密碼或應用程式密碼。授權後可列出最新郵件、套用搜尋條件、寄送測試信，並確認測試信已出現在收件匣。

🔒 授權權杖只保留在目前瀏覽器記憶體；關閉或重新載入頁面即清除。此網頁不會把密碼或權杖寫入 GitHub、localStorage 或執行紀錄。
首次使用需先設定 Google OAuth 用戶端 ID，詳見 README。

寄送測試信

寄給目前登入的帳號時，會自動在收件匣搜尋這封信並顯示驗證結果。寄給其他人時只會回報 Gmail API 的寄送結果。

執行狀態

請先使用 Google 帳戶連線。每次讀信或寄信的結果會顯示在此處。
網頁以 Gmail API 與 OAuth 2.0 運作，這是瀏覽器版的安全替代方案；與使用 16 字元應用程式密碼連線 IMAP/SMTP 的原作業方式不同。
